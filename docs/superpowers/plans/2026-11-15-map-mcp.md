# Agent 地图工具（高德 MCP）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在设置页全局配置高德 Web 服务 Key，把高德官方 HTTP MCP 接入 Agent，让模型可以搜索 POI、做地理编码、规划路线、测距和查天气。

**Architecture:** `settings.json` 新增 `maps` 节；`/api/maps` 提供掩码配置读写；`ClaudeTurnRunner` 在启用且有 Key 时把 `amap` 加入 SDK 的 `mcp_servers`，并把 maps 配置纳入 client 指纹；配置页新增「地图」卡片。Key 只存在后端，日志脱敏。无新依赖、无数据库变更、无地图 UI。

**Tech Stack:** FastAPI（Python 3.12）、Claude Agent SDK（`McpHttpServerConfig`）、React 18 + TypeScript + Vite、pytest。

**依据设计：** `docs/superpowers/specs/2026-11-15-map-mcp-design.md`

```markdown
### F24 Agent 地图工具

- 状态：现行
- 日期：2026-11-15
- 来源：2026-11-15 高德 MCP 地图工具设计

#### 功能点

1. 配置页提供全局「地图」配置：启用开关与高德 Web 服务 Key；所有 Agent 共用，与当前选中的 Agent 无关。Key 只保存在后端；`GET/PUT /api/maps` 只返回 `enabled`、`provider`、`has_api_key`，不返回 Key。
2. 启用且有 Key 时，Agent 可调用高德官方 MCP 的工具（POI、地理/逆地理编码、驾车/公交/步行/骑行路线、距离、天气等）；停用或无 Key 时不连接。
3. 启用但没有可用 Key 时保存返回 400；提交空白 Key 保留已保存 Key；清除 Key 会把开关置为停用并优先于新提交的 Key。
4. 修改 Key 或开关后，同一已缓存会话的下一轮对话按新配置重建 client 并生效；修改时正在执行的 turn 仍按旧配置完成。
5. 高德 MCP 不可用或 Key 无效时，普通聊天继续，地图工具失败；该 Agent 完成一轮对话后，工具页的 MCP 服务列表出现 `amap`，连接失败时状态显示「连接失败」。
6. Key 不写入前端响应、`.env`、仓库或运行日志；CLI stderr 调试日志中的 Key 显示为 `***`。
7. 本期不做聊天内地图渲染、路线可视化或独立地图页面，也不接其他地图提供商。

#### 验收标准

- 使用真实高德 Web 服务 Key 手工验证（需联网）：启用后，在同一会话的下一轮对话或新会话中提问附近 POI、路线、天气，Agent 调用 `mcp__amap__*` 并返回真实结果；自动化测试只验证 `amap` MCP 已注入且 URL 编码正确。

- 修改 Key 或开关后，已缓存会话的下一轮对话使用新配置；进行中的 turn 不受影响。
- 无效 Key（需联网）时普通聊天正常，地图工具调用失败；工具页的 `amap` 服务状态以其真实连接结果为准（连接失败时显示「连接失败」）。
```

```python
from __future__ import annotations

from fastapi import APIRouter, Depends, HTTPException, Request

from app.auth import require_auth
from app.schemas import MapsConfigUpdate
from app.services.settings_store import (
    MapsSection,
    SettingsStore,
    get_settings_store,
)

router = APIRouter(
    prefix="/api/maps", tags=["maps"], dependencies=[Depends(require_auth)]
)


def _store(request: Request) -> SettingsStore:
    store = getattr(request.app.state, "settings_store", None)
    return store if store is not None else get_settings_store()


def _config_out(section: MapsSection) -> dict[str, object]:
    return {
        "enabled": bool(section.enabled),
        "provider": section.provider or "amap",
        "has_api_key": bool(section.api_key),
    }


@router.get("")
async def get_maps(request: Request) -> dict[str, object]:
    return _config_out((await _store(request).get()).maps)


@router.put("")
async def update_maps(
    payload: MapsConfigUpdate, request: Request
) -> dict[str, object]:
    store = _store(request)
    current = (await store.get()).maps
    fields: dict[str, object] = {}

    if payload.clear_api_key:
        fields["api_key"] = ""
        fields["enabled"] = False
    else:
        if payload.api_key is not None and payload.api_key.strip():
            fields["api_key"] = payload.api_key.strip()
        if payload.enabled is not None:
            fields["enabled"] = bool(payload.enabled)
        next_key = str(fields.get("api_key", current.api_key) or "").strip()
        next_enabled = bool(fields.get("enabled", current.enabled))
        if next_enabled and not next_key:
            raise HTTPException(
                status_code=400, detail="请先填写高德 Web 服务 Key"
            )

    if fields:
        await store.update_maps(**fields)
    return _config_out((await store.get()).maps)
```

```tsx
    const trimmed = apiKey.trim();
    if (enabled && !config?.has_api_key && !trimmed) {
      setError("请先填写高德 Web 服务 Key");
      return;
    }
    setSaving(true);
    setError("");
    setNotice("");
    try {
      const next = await api.updateMapsConfig({
        enabled,
        ...(trimmed ? { api_key: trimmed } : {}),
      });
      setConfig(next);
      setEnabled(next.enabled);
      setApiKey("");
      setNotice("已保存，下一轮对话生效。");
    } catch (exc) {
      setError(errorText(exc));
    } finally {
      setSaving(false);
    }
  }

  async function clearKey() {
    if (clearing) return;
    setClearing(true);
    setClearOpen(false);
    setError("");
    setNotice("");
    try {
      const next = await api.updateMapsConfig({ clear_api_key: true });
      setConfig(next);
      setEnabled(false);
      setApiKey("");
      setNotice("已清除高德 Key 并停用地图工具。");
    } catch (exc) {
      setError(errorText(exc));
    } finally {
      setClearing(false);
    }
  }

  const saveDisabled =
    saving ||
    (enabled && !config?.has_api_key && !apiKey.trim());

  return (
    <>
      <form className="editor" onSubmit={save}>
        <label className="toggle-row" htmlFor="maps-enabled">
          <input
            id="maps-enabled"
            type="checkbox"
            checked={enabled}
            onChange={(event) => setEnabled(event.target.checked)}
          />
          <span>
            <strong>启用高德地图工具</strong>
            <small>启用后所有 Agent 都可以搜索地点、规划路线和查天气</small>
          </span>
        </label>

        <label className="field-label" htmlFor="maps-key">
          高德 Web 服务 Key
        </label>
        <input
          id="maps-key"
          type="password"
          value={apiKey}
          onChange={(event) => setApiKey(event.target.value)}
          placeholder={
            config?.has_api_key
              ? "已配置，留空保持不变，输入新 Key 可替换"
              : "输入高德 Web 服务 Key（不是 JS API Key）"
          }
        />

        <div className="hint">
          在高德开放平台创建 Web 服务 Key：
          <a
            className="plugin-link"
            href="https://lbs.amap.com/api/mcp-server/create-project-and-key"
            target="_blank"
            rel="noreferrer"
          >
            创建 Key
          </a>
        </div>

        {config?.has_api_key && (
          <div className="form-actions">
            <span className="key-badge ok">密钥已配置</span>
            <button
              type="button"
              className="ghost-button"
              onClick={() => setClearOpen(true)}
              disabled={saving || clearing}
            >
              清除密钥
            </button>
          </div>
        )}

        {error && <div className="error-banner">{error}</div>}
        {notice && <div className="hint">{notice}</div>}

        <div className="form-actions">
          <button className="primary" type="submit" disabled={saveDisabled}>
            {saving ? "保存中…" : "保存地图配置"}
          </button>
        </div>
      </form>

      <div className="hint">
        保存后下一轮对话生效；可在「工具」页查看 amap 服务的连接状态。
        无效 Key 时地图工具会失败，但普通聊天不受影响。
      </div>

      <ConfirmDialog
        open={clearOpen}
        title="清除地图 Key？"
        description="清除后高德地图工具会停用，需要重新填写 Key 才能恢复。"
        confirmLabel="清除"
        danger
        onClose={() => setClearOpen(false)}
        onConfirm={() => void clearKey()}
      />
    </>
  );
}
```
