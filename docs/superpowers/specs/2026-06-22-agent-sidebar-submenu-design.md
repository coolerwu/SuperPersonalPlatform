# Agent 侧栏子菜单设计

## 目标

将 Agent 的“对话、Agent 管理、Skill 管理、模型配置”从页面内部功能轨道上移到全局侧栏的 Agent 子菜单，消除双层导航并扩大工作区。

## 路由与行为

- `/agents`：对话。
- `/agents/manage`：Agent 管理。
- `/agents/skills`：Skill 管理。
- `/agents/models`：模型配置。
- `/models`：兼容入口，继续打开模型配置。
- 点击顶层 `Agent` 默认进入 `/agents`；位于任一 Agent 子路由时，顶层 Agent 和对应子项同时显示选中状态。
- 页面内容、API、表单状态和保存行为保持不变，仅移除页面内 `agent-mode-rail`。
- 桌面端子菜单在 Agent 下方缩进显示；移动端作为横向第二级导航，允许水平滚动。

## 验收

- 自动化测试覆盖四个子菜单、路由切换、兼容路由和页面内轨道移除。
- 浏览器验证桌面和移动端均无内容遮挡或横向页面溢出。
